Whono for Utterlog —— 上游来源与许可
=====================================

本主题是 astro-whono 的 Utterlog 移植版，视觉设计与版式取自上游项目。

  上游项目：astro-whono
  仓库地址：https://github.com/cxro/astro-whono
  作者：cxro
  许可：MIT License
  移植日期：2026-09-26

移植内容：双栏壳（左侧栏 + 1px 分隔线 + 正文）、衬线正文与楷体注解的字体分工、
          克制的朱红强调色、浅色/深色令牌、列表行与归档行的版式、阅读模式。
改写内容：由 Astro 组件改写为 Utterlog 的 React 主题组件，接入
          useThemeContext / AppLink / PostLink / 共享评论与目录组件；
          深色模式改用 data-whono-color 属性（Utterlog 的 data-theme 被主题名占用）。
